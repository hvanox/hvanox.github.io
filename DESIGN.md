# DESIGN.md — hvano.dev

Эстетика: **old-web максимализм** (Neocities / Web 1.0 / Y2K) × **breakcore** × **Kasane Teto** × **90-е**.
Ощущение: чужая личная страница 2004-го, найденная в архиве, но собранная на современном стеке и работающая быстро.
Не минимализм. Не корпоративный SaaS. Плотность — часть смысла.

## Палитра

| Токен | Hex | Роль |
|---|---|---|
| `--color-void` | `#00182C` | фон страницы (тёмный морской, из требований) |
| `--color-void-deep` | `#000D18` | провалы, внутренности окон |
| `--color-blood` | `#EB0038` | главный акцент: Teto-красный, рамки, hover, глитч |
| `--color-blood-dim` | `#8F0022` | притушённый акцент, границы в покое |
| `--color-bone` | `#E2E2E2` | основной текст |
| `--color-bone-dim` | `#8A97A2` | вторичный текст, подписи авторов |
| `--color-cyan` | `#00E5FF` | второй акцент: ссылки, глитч-канал (от меня) |
| `--color-acid` | `#C8FF00` | редкий третий акцент: статусы «online», ачивки |
| `--color-chrome` | `#9AA7B4` | «металл» 90-х: бордюры окон, скроллбар |

Правила: `blood` и `cyan` рядом только через глитч (RGB-сплит), не в одном тексте. `acid` — не больше трёх пятен на экран.

## Типографика

| Роль | Шрифт | Как |
|---|---|---|
| Дисплей | `VCR OSD Mono` / fallback `Anton`, `Impact` | капс, широкий трекинг, обводка + тень |
| Основной | `IBM Plex Mono` | всё тело текста моноширинное — это терминал, не журнал |
| Пиксель | `Silkscreen` (Google Fonts) | бейджи 88×31, счётчики, лейблы окон |
| Японский | `Zen Kaku Gothic New` | `重音テト`, катакана-декор |

Всё через `next/font/google`, self-host, никакой внешней загрузки в рантайме.
Заголовки — `text-transform: uppercase`, `letter-spacing: .08em`. Тело — 14px, `line-height: 1.45`. Мелкая подпись автора арта — 10px `--color-bone-dim`.

## Layout

Три колонки на десктопе, стек на мобиле (референсы — только десктоп, но мы адаптивные).

```

│ HEADER: логотип HVANO глитч + 重音テト + слоган + lang                         │
├───────────────┬────────────────────────────────────┬────────────────────────┤
│ LEFT (240px)  │ CENTER (fluid)                     │ RIGHT (240px)          │
│ • плеер       │ • WELCOME / about                  │ • github-статы         │
│ • nav-меню    │ • STACK (сетка бейджей)            │ • now playing          │
│ • updates log │ • ACHIEVEMENTS (окна win98)         │ • Teto shrine (арты)  │
│ • 88×31 кнопки│ • PROJECTS (карточки-скриншоты)     │ • guestbook-заглушка   │
│               │ • CONTACT (терминал)               │ • webring кнопки       │
├───────────────┴────────────────────────────────────┴────────────────────────┤
│ FOOTER: © hvano 2026 · badges · «under construction» gif-ish                 │
```

Слои: фон (grid + шум + скан-линии) → зигзаг-полосы Teto по краям viewport → колонки → окна → «выступающие» арты Teto поверх сетки, ломающие прямоугольник.

## Компоненты-обвязка (`components/chrome/`)

- `Win98Window` — заголовок-полоса `--color-chrome`, кнопки `_ □ ×` (декоративные, `aria-hidden`), тень 2px без блюра. Основной контейнер для секций.
- `LaceFrame` — рамка через `border-image` из SVG-кружева, но в breakcore-варианте: не кружево, а пилообразный зигзаг `--color-blood`.
- `Marquee` — CSS-анимация, не тег `<marquee>`; уважает `prefers-reduced-motion`.
- `GlitchText` — три слоя (bone / blood / cyan) со случайным `clip-path`, только на hover и на заголовке hero.
- `Badge8831` — пиксельные баннеры 88×31 в духе webring, вместо чужих сайтов — технологии стека.
- `Player` — Winamp-подобный поверх официальных клипов YouTube (iframe API, видеоэкран скрыт 1×1 — только звук). Свой транспорт, живых аудиоданных из JS нет — визуализатор заменён статичной полосой. Сверху `LyricsBar`: текст текущей песни бегущей строкой, крутится пока играет. Автоплей включён: сначала со звуком, при блокировке браузером — немой + кнопка размьюта.
- `TetoArt` — `<img>` + мелкая подпись `art: {artist}` под ним, `loading="lazy"`, `decoding="async"`.
- `ScanlineOverlay` — `pointer-events: none`, `mix-blend-mode: overlay`, отключается при reduced-motion.

## Breakcore-приёмы

- Рубленая сетка: блоки чуть повёрнуты (`rotate(-.4deg)`), не выровнены пиксельно.
- RGB-сплит на hover заголовков и на аватарке.
- Резкие «стробы» — только по hover/фокусу, никогда сами по себе (эпилепсия + reduced-motion).
- Datamosh-текстуры генерируем SVG-фильтрами (`feTurbulence`, `feDisplacementMap`), не картинками.
- Каунтеры и «updates log» с настоящими датами из git — правдиво, а не декорация.

## Доступность (не жертвуем ради вайба)

- Контраст текста к фону ≥ 4.5:1: `bone` на `void` = ок; `blood` только на `void-deep` и крупным кеглем.
- `prefers-reduced-motion: reduce` глушит marquee, глитчи, скан-линии, визуализатор.
- Все декоративные картинки `alt=""`, арты Teto — осмысленный alt.
- Клавиатурная навигация: видимый `:focus-visible` — `outline: 2px solid var(--color-cyan)`.
- Плеер с явными кнопками и `aria-label`, звук не стартует без клика.
- Полная валидация WCAG требует ручного теста со скринридером и экспертного ревью — здесь сделаны только автоматизируемые вещи.

## Что осознанно НЕ берём из референсов

Чужие Sanrio/аниме-ассеты (авторские права), настоящий `<marquee>`, фиксированную ширину 1920, autoplay-музыку, «плохой accessibility как часть эстетики».
