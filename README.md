# hvano.dev

**Live:** https://hvanox.github.io

Сайт — это эдит Kasane Teto от **reathaa**, пересобранный в коде: каждая
панель, окно и кнопка эдита свёрстаны заново и несут живые данные (профиль,
стек, GitHub, плеер, достижения, лог обновлений, фанарты). Координаты панелей —
пиксели исходника 736×414 (`--u` = один пиксель референса), поэтому борд
масштабируется целиком и всегда вписан в окно без прокрутки; если окно выше,
чем 16:9, борд чуть растягивается по высоте. На телефоне это та же картинка:
горизонтально — на весь экран, вертикально — с подсказкой повернуть телефон.

Тето в центре — официальный арт Synthesizer V 2 (© TWINDRILL, illust. 線).

Прошлые версии:
- win98 / брейккор — в `portfolio/` (архив, в сборку не входит);
- борд поверх картинки на Next.js — в истории, коммит `f7a9ab1`.

## Стек

Vite · React 19 · TypeScript · Tailwind CSS v4 · Motion · Phosphor Icons · YouTube iframe API

## Разработка

```bash
pnpm install
pnpm dev          # http://localhost:5173
pnpm lint
pnpm build        # статика в dist/
```

Деплой: GitHub Actions на каждый пуш в `main` (`.github/workflows/deploy.yml`).

## Где что

- `src/content/` — все тексты и данные (профиль, словарь ru/en, плейлист, арты, лог обновлений).
- `src/components/blocks/` — панели борда, `src/components/ui/` — примитивы и модальное окно.
- `src/App.tsx` — расстановка панелей, Тето, анимации (включение ЭЛТ, печать, глубина за мышкой).
- `src/lib/player.tsx` — плеер поверх официальных клипов на YouTube (просмотры идут авторам).
- `vite.config.ts` — Content-Security-Policy и Referrer-Policy для продакшен-сборки.

Язык можно задать ссылкой: `?lang=ru` / `?lang=en`.
Автор каждого фанарта подписан под изображением на сайте.
